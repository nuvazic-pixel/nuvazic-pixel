# Selected Data Analytics Projects — CV-ready wording
Use three projects per application and retain their status labels. These entries describe published work; they do not claim employment outcomes, commercial adoption or independently verified source-data results.

## English

### NetGrid — FTTH Scenario Reporting | Python, pandas, SQLite, Streamlit, Plotly
Portfolio prototype connecting telecommunications infrastructure experience with analytical reporting. Compared subscriber take-rate scenarios using explicit assumptions for homes, construction cost and monthly revenue. Published a reproducible script and results table showing how take rate changes subscribers and annual sales value while CAPEX remains fixed. Municipal FTTH metrics are simulated.

### Magist — Marketplace & Delivery Analysis | MySQL, Tableau
Data Analytics coursework examining marketplace fit for a technology retailer. Used joins, grouped aggregations and date calculations to explore product mix, seller activity and delivery performance; presented analysis through SQL and Tableau screenshots. Documented KPI definitions and corrected the late-delivery denominator using the counts recorded in the SQL worksheet. Source-database rerun pending.

### GANS — European Cities ETL | Python, pandas, APIs, BeautifulSoup, MySQL
Coursework pipeline combining city information from web scraping with weather and flight API responses. Structured the data into six related MySQL tables, including a city–airport junction table. Practised extraction, JSON normalisation, relational modelling and database loading. End-to-end execution requires API credentials and a local MySQL database; current notebook has no saved outputs.

### Eniac — Pricing & Data Quality | Python, pandas, Matplotlib
Coursework notebooks for transaction exploration, duplicate and missing-value checks, joins, discount features and seasonal comparisons. Implemented descriptive analysis code and documented metric definitions and limitations. Portfolio work in progress: source-data execution and evidence-backed conclusions remain to be completed.

## Deutsch

### NetGrid — FTTH-Szenarioanalyse | Python, pandas, SQLite, Streamlit, Plotly
Portfolio-Prototyp zur Verbindung von Erfahrung im Glasfaserausbau mit analytischem Reporting. Vergleich von Anschlussquoten bei expliziten Annahmen zu Haushalten, Ausbaukosten und monatlichen Erlösen. Reproduzierbares Skript mit Ergebnistabelle zu Teilnehmerzahl und jährlichem Umsatz bei konstanten Investitionskosten veröffentlicht. FTTH-Kennzahlen der Gemeinden sind simuliert.

### Magist — Marktplatz- und Lieferperformance | MySQL, Tableau
Kursprojekt zur Eignung eines Marktplatzes für einen Technologiehändler. Untersuchung von Produktmix, Verkäuferaktivität und Lieferzeiten mit Joins, Aggregationen und Datumsfunktionen; Darstellung durch SQL-Auswertung und Tableau-Screenshots. KPI-Definitionen dokumentiert und den Nenner der Verspätungsquote anhand gespeicherter Zählwerte korrigiert. Erneute Ausführung mit Quelldaten steht aus.

### GANS — ETL für europäische Städte | Python, pandas, APIs, BeautifulSoup, MySQL
Kursprojekt zur Zusammenführung von Stadtinformationen aus Web Scraping mit Wetter- und Flugdaten aus APIs. Strukturierung in sechs verknüpfte MySQL-Tabellen einschließlich einer Zuordnungstabelle für Städte und Flughäfen. Geübt wurden Extraktion, JSON-Normalisierung, relationale Modellierung und Datenbankimport. Vollständige Ausführung erfordert API-Zugänge und eine lokale MySQL-Datenbank; gespeicherte Notebook-Ausgaben fehlen derzeit.

### Eniac — Preisanalyse und Datenqualität | Python, pandas, Matplotlib
Kursnotebooks für Datenexploration, Dubletten- und Fehlwertprüfungen, Tabellenverknüpfungen sowie Rabatt- und Saisonanalysen. Deskriptiven Analysecode umgesetzt und Kennzahlendefinitionen sowie Grenzen dokumentiert. In Bearbeitung: Ausführung mit Quelldaten und daraus abgeleitete Schlussfolgerungen.
